Shopping Lists – Frontend submission

Teacher instructions: how to run and how to verify requirements
Project goal
  • Frontend communicates with the backend (load/save data via server API).
  • Frontend can run in Mock mode (server calls are mocked by local mock data).
  • UI improvements: charts (statistics), Light/Dark mode, responsive layout, multilingual UI (EN/CZ).

1) How to run the project

Requirements: Node.js + npm installed.

  1. Open terminal in the project folder (where package.json is).
  2. Install dependencies:
npm install
  1. Start development server:
npm start

The application will open in the browser (usually http://localhost:3000).

2) Mock mode vs Real backend

Mock mode (recommended for quick evaluation)
  • In the top right corner there is a toggle: Mock mode: ON/OFF.
  • When Mock mode is ON, the app uses built-in mock data and does not require backend.
Real backend mode
  • Set Mock mode to OFF.
  • Make sure backend is running at REACT_APP_API_BASE_URL (default: http://localhost:3001).
  • If backend is not running, the UI will show a fetch error (expected behavior).

3) What to test (requirements checklist)

A) Communication with server (backend)

  • Switch Mock mode to OFF and ensure backend is running.
  • Open Lists overview – lists are loaded from server.
  • Create a new list using Add new list.
  • Delete a list – confirmation dialog is shown.

B) Mocking server calls

  • Switch Mock mode to ON.
  • Verify that lists are loaded from mock data.
  • Create/delete actions work in mock mode as well.

C) Charts / statistics

  • Open a specific shopping list detail page (click any tile).
  • Verify the pie chart shows Solved vs Unsolved items.
  • In overview, item counts are displayed (visual bar + count).

D) UI improvements

  • Light/Dark: switch theme using the toggle in the top bar.
  • Responsive layout: resize browser window – layout adapts.
  • Multilingual UI: switch language (EN/CZ). Data content (list names/items) remains unchanged.

4) Environment notes

The frontend reads configuration from .env (Create React App):

REACT_APP_API_BASE_URL=http://localhost:3001
REACT_APP_USE_MOCK=false

Mock mode can be switched at runtime via UI toggle (top right).
