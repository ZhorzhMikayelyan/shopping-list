How to run the project

1. Install dependencies

In the root folder of the project, run:

npm install

2. Start the development server

Then run:

npm start

This will open the application in the browser at http://localhost:3000.

3. Main routes

  • /lists – overview of all shopping lists (tiles, add, delete).
  • /lists/:id – detail of a single shopping list.

4. Build (optional)

To create a production build, run:

npm run build

The optimized build will be generated in the build/ folder.
